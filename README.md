# 🏥 MediControl - Sistema de Gestión Clínica

MediControl es un sistema web para la gestión de una clínica, desarrollado con backend en Spring Boot, base de datos MySQL y frontend en React + Bootstrap.

El sistema permitirá administrar pacientes, médicos, especialidades, citas médicas y usuarios con roles.

---

## 🚀 Tecnologías utilizadas

### Backend
- Java 17
- Spring Boot 3.2.5
- Spring Web
- Spring Data JPA
- MySQL
- Maven
- Lombok
- Validation

### Frontend
- React
- Bootstrap
- Axios
- React Router DOM
